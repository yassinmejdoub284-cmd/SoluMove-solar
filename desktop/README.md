# SoluMove Solar Desktop

La version de bureau livrée en première version est une PWA installable sous Windows, macOS et Linux avec Chrome/Edge. Elle utilise le même espace privé et les mêmes données que l'application web, et conserve un instantané local pour consultation hors ligne.

## Installation
1. Ouvrir l'URL privée publiée dans Chrome ou Edge et se connecter.
2. Ouvrir Paramètres → Application de bureau → Installer, ou utiliser l'option d'installation du navigateur.
3. Choisir la langue dans la barre supérieure : français, arabe ou anglais.

## Fonctionnement hors ligne
La consultation du dernier instantané est disponible après un premier chargement en ligne. La création ou modification de transactions financières et de mouvements de stock requiert une connexion. Il n'y a pas de serveur local de production ni de synchronisation multi-poste hors ligne dans cette version.

## Application native
Une distribution .exe signée, un serveur local et une file d'écriture hors ligne nécessitent une étape séparée de packaging et de validation sur Windows. Aucun exécutable natif n'est présenté comme livré par cette version.
